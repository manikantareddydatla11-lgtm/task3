# Responsive Image Gallery

## Project Overview

This project is a responsive image gallery developed using HTML5, CSS3, and JavaScript. It displays eight images in a grid layout and allows users to view images in a larger lightbox preview.

## Objectives

- Learn CSS Grid and responsive web design.
- Practice JavaScript click events.
- Create an interactive image preview.
- Implement previous, next, and close controls.
- Improve basic UI and accessibility skills.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash for sample images

## Features

- Responsive image grid.
- Minimum of eight images.
- Clickable image previews.
- Lightbox modal.
- Previous and next image navigation.
- Close button and Escape key support.
- Left and right arrow keyboard navigation.
- Image descriptions using alt attributes.

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Click any image to view the larger preview.
5. Use the navigation arrows to browse images.
6. Close the preview using the close button or Escape key.

## Image Sources

Sample images are loaded from Unsplash. An internet connection is required to load these images.

## Learning Outcomes

This project demonstrates the use of semantic HTML, CSS Grid, media queries, DOM manipulation, event listeners, and interactive modal previews.
